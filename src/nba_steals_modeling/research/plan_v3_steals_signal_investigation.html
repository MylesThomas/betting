Correct filter: vig-based, not sign-based

def american_to_implied_prob(odds):
    if odds < 0: return (-odds) / ((-odds) + 100)
    return 100 / (odds + 100)

df["vig"] = (df["over_odds"].apply(american_to_implied_prob)
           + df["under_odds"].apply(american_to_implied_prob))

# Flag rows where vig is outside plausible range
# Real markets: 100% < vig < 120%. Near-zero odds blow this up.
df_clean = df[(df["vig"] >= 1.00) & (df["vig"] <= 1.20)].copy()
print(f"Rows passing vig filter: {len(df_clean):,}")

This correctly keeps Alex Caruso (+105 under, vig ≈ 107%) and removes Suggs' -0.5 row (vig ≈ 257%).

Phase 3 — v3 Notebook Build

Build Only proceed here if Phase 1 + 2 confirm the signal. Notebook: v3_steals_1_5_under_model.ipynb

What the model adds over the flat rule

The flat rule bets everything including 35+ min players (zero edge). A model filters to the high-confidence spots within the universe.

FeatureRationale
stl_roll20, stl_roll40Settled steal rate — longer window more stable for low-frequency stat
min_roll10Minutes context — primary driver of steal opportunity volume
stl_per_min_roll20Rate-normalized steal tendency
market_p_over (de-vigged)Where market thinks the line is — gap vs model = edge

Model approach

Two options — test both:

  • Option A — Logistic regression: direct P(STL ≥ 2) classifier. Same as v1 but restricted to <35 min population where the edge exists. v1 was trained on everything including stars where there's no signal.
  • Option B — Poisson rate model: estimate each player's λ (steal rate per game), compute P(X ≥ 2) = 1 − Poisson.cdf(1, λ). More principled for count data. Shrink λ estimates toward population prior (Empirical Bayes).
Option B is worth testing — see the population prior approach. Key difference: shrink toward the DATA prior (observed steal rates), not toward the market. The market prior is demonstrably wrong for low-minute players.

Evaluation criteria

  • Walk-forward ROI must be positive in 2/3 seasons at min_edge=0.05
  • Model ROI must beat flat-rule ROI on the same filtered universe (otherwise just use the flat rule)
  • n_bets ≥ 300 per test season at the chosen threshold (below this is noise)

Why the oracle signal doesn't translate

The +16% edge comes from players who unexpectedly played under 25 minutes — starters in blowouts, foul trouble, load management decisions made same-day. These situations are not predictable pre-game. The players who always play under 25 minutes (true bench players, min_roll10 < 25) are already priced correctly by the market, hence -15.9% ROI.
