The key difference vs steals: ball-handler share changes are often known before the game (injury report, confirmed starter listings). This is the hypothesis to test.

Hypotheses to Test

  1. Ball-handler lag: When a team's primary PG sits, the backup PG's assists line was set before the lineup news. Market underprices the backup's over, overprices the starter's under. Testable via rolling average vs posted line comparison.
  2. High-line regression: Players on 7.5+ lines have high-assist games baked into the line. After a 12-assist game, the next line is set too high — bet the under. Anchoring bias in line-setting.
  3. Role player wrong line: Non-PG players (wings, bigs) sometimes have a 3.5 line despite averaging 2.8 AST. Market sets the line by formula (last 3 games avg) and a couple high-assist games inflate it. Same mechanism as steals 1.5 line for low-steal players.
  4. Calibration gap by line tier: Like steals (0.5 line was perfectly calibrated, 1.5 line had a 4.2% gap), one tier of the assists market may be systematically mispriced.

Cell 5 — Flat rule: bet every under

# y_under = 1 if AST < prop_line (e.g. AST < 4 on a 3.5 line)
df_clean["y_under"] = (df_clean["AST"] < df_clean["prop_line"]).astype(int)
df_clean["pnl"] = df_clean.apply(
    lambda r: american_profit(r["under_odds"]) if r["y_under"] == 1 else -1.0, axis=1
)

# Overall
print(f"n={len(df_clean):,}  hit_rate={df_clean['y_under'].mean():.3f}  ROI={df_clean['pnl'].mean()*100:.2f}%")

# By season
print(df_clean.groupby("season")[["y_under","pnl"]].mean().rename(
    columns={"y_under":"hit_rate","pnl":"roi"}).round(3))

Cell 6 — Segment by line tier

Cell 7 — Calibration by line tier

df_clean["p_mkt_dv"] = (df_clean["over_odds"].apply(american_to_implied_prob)
                       / df_clean["vig"])
# p_mkt_dv = de-vigged P(over). Calibration gap = p_mkt_dv - actual_over_rate.
df_clean["y_over"] = (df_clean["AST"] >= df_clean["prop_line"]).astype(int)
cal = df_clean.groupby("line_tier", observed=True).apply(lambda g: pd.Series({
    "mkt_p_over": g["p_mkt_dv"].mean(),
    "actual_over": g["y_over"].mean(),
    "gap": g["p_mkt_dv"].mean() - g["y_over"].mean(),
    "n": len(g),
}), include_groups=False)
print(cal.round(4))
In steals, the 1.5 line had a 4.2% calibration gap (market overpriced the over). Look for any tier here with gap > 3%.

Cell 9 — Rolling average vs line (the lag hypothesis)

# Pre-game proxy: player's recent AST average vs the posted line
# If ast_roll10 << prop_line, market may have set line based on stale data
dc = df_clean.sort_values(["PLAYER_NAME","season","game_date"]).copy()
dc["ast_roll10"] = dc.groupby(["PLAYER_NAME","season"])["AST"].transform(
    lambda s: s.shift(1).rolling(10, min_periods=5).mean()
)
dc["line_vs_roll"] = dc["prop_line"] - dc["ast_roll10"]  # positive = line set above rolling avg

# Does betting under when line_vs_roll > +1 show edge?
print("=== Under ROI by (prop_line - ast_roll10) bucket ===")
dc["lag_bucket"] = pd.cut(dc["line_vs_roll"],
    bins=[-20, -2, -1, 0, 1, 2, 20],
    labels=["line << avg", "line < avg", "line ≈ avg-", "line ≈ avg+", "line > avg", "line >> avg"]
)
print(dc.groupby("lag_bucket", observed=True)[["y_under","pnl"]].agg(
    count=("pnl","count"), hit_rate=("y_under","mean"), roi=("pnl","mean")).round(3))
This is the key test: if prop_line >> ast_roll10 (market set the line high relative to recent average), does the under have edge? This is the "anchoring bias" hypothesis.
