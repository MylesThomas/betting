# NBA vs NFL: Sport-Specific Patterns

**Status:** 📝 Planned - YOUR EXPERTISE NEEDED  
**Last updated:** 2026-02-13

This document will explain key differences between NBA and NFL betting.

## Planned Sections

### Market Volume

**NBA:**
- Games almost every day (high volume)
- More liquid markets
- Player props widely available
- More historical data per season

**NFL:**
- Games once per week (low volume)
- Less liquid markets
- Fewer player props (more team-focused)
- Smaller sample sizes

### Market Efficiency

**NBA:**
- High efficiency (sharp bettors active)
- Edges are small
- Props close quickly
- Need sophisticated models

**NFL:**
- Moderately efficient
- More public bias (popular teams overbet)
- Luck plays larger role (small sample)
- Injuries have huge impact

### Data Availability

**NBA:**
- Rich APIs (NBA.com, stats.nba.com)
- Play-by-play data available
- Shot charts, tracking data
- Real-time box scores

**NFL:**
- More fragmented data
- EPA/CPOE from third parties
- Limited play-by-play APIs
- Injury reports critical

### Betting Strategy Differences

**NBA:**
- Focus on player usage rates
- Matchup-dependent (pace, defense)
- Back-to-backs and rest matter
- Garbage time affects props

**NFL:**
- Luck regression strategies
- Turnover variance
- Point differential vs record
- Strength of schedule

### Data Sources Used

**NBA:**
- DraftKings, FanDuel for props
- NBA API for game logs
- The Odds API for odds aggregation
- ESPN for scores/schedules

**NFL:**
- The Odds API for spreads/totals
- Unexpected Points for EPA data
- ESPN for schedules
- Limited player props (not main focus yet)
