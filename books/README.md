# Reference Materials

This directory contains notes and transcriptions from external sources.

## Monte Carlo Betting References

These files are reference materials from the book **"Monte Carlo or Bust: Simple Simulations for Aspiring Sports Bettors"** by Joseph Buchdahl:

- **monte_carlo_or_bust.md** - Complete book transcription with prediction models, simulation methods
- **MONTE_CARLO_IMPLEMENTATION_STRATEGY.md** - Implementation notes for applying concepts to this codebase
- **monte_carlo_implementation_guide.md** - Step-by-step guide for Monte Carlo simulations
- **monte_carlo_prediction_models.md** - Notes on prediction model approaches
