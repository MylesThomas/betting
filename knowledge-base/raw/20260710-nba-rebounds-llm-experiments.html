Experiment 1 — Recognition Tier as a Bet Filter (2026-07-10)

Hypothesis

Markets anchor on player identity: books set lines for superstars based on heavy public betting action, while fringe/obscure players receive less sharp attention and softer lines. If true, the model's edge should be higher and more reliable for lower-recognition players.

Two-step test: (1) check raw under hit rates by tier — does any tier systematically beat the population baseline without the model? (2) run the full OLS backtest filtered to each tier — does restricting to a tier improve ROI or consistency vs betting all players?

Findings

  • Superstar = dead weight. 2,250 bets across 3 seasons, only +6u (+0.28% ROI), positive in just 1 of 3. The model has no edge on superstars — likely because books price them efficiently given high public betting volume.
  • Fringe leads in ROI (+7.98%) but is inconsistent: blowout in 2023-24 (+19%) offset by a bad 2024-25 (−7%). Only 2/3 positive seasons.
  • Known_starter is the most consistent: 3/3 positive seasons, adequate volume (4,644 bets), but ROI barely below the all-tier baseline.
  • Excluding superstars would improve the all-tier strategy: n_bets drops from 11,415 → 9,165, PnL stays roughly the same (+559u), ROI lifts from 4.95% → ~6.1%.
Verdict: Weak signal at tier level. No single tier dominates consistently. The clearest finding is that superstar bets should be excluded — +6u / +0.28% ROI across 3 seasons while consuming 20% of bet volume. Grid search below confirms this is robust.
