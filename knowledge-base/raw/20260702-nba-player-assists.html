Prior Attempt Summary (v1 — archived)

v1 (archive/nba_assists_modeling_archived/research/scripts/v1_assists_model_vs_market.py) mirrored the rebounds v5 script — OLS/Ridge/XGB walk-forward OOS on raw AST. Key findings:

  • OLS and Ridge beat market by ~1% RMSE in both OOS folds — consistent but tiny
  • XGB overfit on thin training data (fold 1 train = 5,023 rows)
  • Best single predictor was max_line — the posted line is essentially the signal
  • Rolling AST averages all lost to the market line alone
  • 1% RMSE improvement evaporates after vig — no tradeable edge found
  • Conclusion: need features the market hasn't priced (lineup changes, ball-handler role expansion, pace, TOV context)

New Approach Hypothesis

The market prices AST off season-average rolling stats. It is slow to update when a player's ball-handler role changes (backup PG picks up AST load when PG1 is out; star's AST spikes when teammates shoot worse). New angles to test vs v1:

  • AST/MIN ratio rolling — role efficiency, not raw volume; captures role expansion better than raw AST
  • TOV rolling — ball-handling volume proxy (high TOV = more possessions in hands)
  • FG3A rolling — inverse signal: heavy 3-point shooters assist less per minute
  • Recent spike detector — last-3-games AST vs 20-game baseline (role change signal)
  • Line disagreement — (max_line − min_line) > 0.5 signals genuine book uncertainty = opportunity
  • Home/away — from MATCHUP field in game logs
  • Framework shift: rather than regressing to predict AST then comparing to line, follow rebounds methodology — use OLS prediction + Normal CDF to get P(over), then compare to market-implied P. This directly targets profitability rather than RMSE.

Key Findings

  • Market is dominant: `consensus_line` is the only feature that beats the market alone (delta −0.008). Every box score feature is strictly worse.
  • Longer rolling windows are better: ast_roll_60 (+0.033) > ast_roll_20 (+0.041) > ast_roll_10 (+0.068) > ast_roll_5 (+0.117) > ast_roll_3 (+0.176) — exactly the same pattern as rebounds.
  • Role-change spike (ast_spike_3v20) is the worst feature: delta +0.788. Recent role changes add noise, not signal. The hypothesis that the market lags on role changes is NOT supported by univariate evidence.
  • TOV, FG3A, MIN, is_home: All add noise when used alone — but may add marginal signal in combination with the market price.
  • AUC max = 0.5066 (is_home): None of the features discriminate over/under outcomes individually. This is expected in a near-efficient market — edge comes from combinations and comparing model residuals to market-implied probability, not from raw AUC.

Step 5 — Out-of-Sample Grid Search

Setup

Uses OOF edge values from Step 4 (20,691 rows across 2 walk-forward folds: test=2024-25, test=2025-26). Flat-bet 1 unit per bet. Odds computed correctly: each book's American odds converted to decimal profit before averaging across books (not arithmetic mean of American odds, which is invalid). Bug Fix: American Odds Averaging

The Step 4 parquet contained avg_over_odds computed as arithmetic mean of American odds (e.g., mean=−31), which is mathematically invalid. A prior v5 run using that column incorrectly showed 50%+ ROI on all strategies — a clear leakage flag. The fix: load assists_props_raw.parquet, convert each book's American odds to profit-space per row, then average. This produced realistic ROI values in the −3% to +2.5% range consistent with real-world betting market efficiency.

Model — Inline OLS (no pickle)

The production model does NOT use a pickle file. Coefficients are hardcoded in run_pipeline.py:

OLS_COEF = {const: 0.2876, min_line: 0.4478, max_line: 0.3403, ast_roll_20: 0.1833}
RESID_STD = 2.1153

# P(over) = 1 - Normal_CDF((line - yhat) / RESID_STD)
yhat = const + min_line * x_min + max_line * x_max + ast_roll_20 * x_roll20
p_model = 1 - norm.cdf((consensus_line - yhat) / RESID_STD)
edge = p_model - p_market  # no-vig market prob
# BET if edge >= 0.10, direction = OVER
