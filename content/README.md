# Content Directory

Betting analysis posts for different platforms.

## File Structure

Name files: `YYYYMMDD [platform] [topic].md`

Each file has 2 sections:
1. **CONTEXT & NOTES** - internal data, model outputs, luck values, insights, pattern notes
2. **THE POST** - public-facing content (no specific luck values to protect model)

## Platform Styles

**Twitter**: casual, lowercase, short tweets or threads

**Substack**: 
- Concise, data-focused (1-2 sentences per play max)
- Matter-of-fact tone, avoid hyperbole ("overperformed" not "massively overperformed")
- Order plays by strength of signal (luck differential for NFL)
- No specific luck numbers in public post (keep those in context section only)
- Include best lines, game times, brief narrative for each play

File convention: `YYYYMMDD [platform] [topic].md`

## Good Data Sources

**For NFL Game Context:**
1. **RotoWire NFL Betting** - https://www.rotowire.com/betting/nfl/
   - News, injury reports, betting line movements
   
2. **ESPN NFL** - https://www.espn.com/nfl/schedule
   - Go to team pages → News → Articles for game previews and storylines
   
3. **NFL.com**
   - Official news, game previews, player updates

**Workflow for Posts:**
1. Run model, capture outputs in CONTEXT & NOTES section
2. Include all internal data: specific luck values, differentials, pattern notes
3. Order plays by signal strength (e.g. luck differential for NFL)
4. Write THE POST section:
   - Remove specific luck numbers (protect model)
   - Keep it concise (1-2 sentences per pick)
   - Use measured language, avoid hyperbole
   - Include best lines and game times
   - Add brief narrative about why each play makes sense
5. Optional: Research games via sources above to add context/color

**Key Rule:** Model data stays in CONTEXT section. Public post gets sanitized version.
