# Transcripts

## File Naming Convention

All files follow the format: `YYYYMMDD Title.extension`

## File Types

### `.txt` - Raw Transcripts
YouTube video transcripts (verbatim text)

**Example:** `20251223 Where Market Making Meets Market.txt`

### `.md` - Notes & Learning
Structured notes, summaries, and key takeaways from the content

**Example:** `20251223 Where Market Making Meets Market.md`

---

Both files share the same base name for easy pairing and reference.
