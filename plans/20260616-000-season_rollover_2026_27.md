## Part 2 — Fix Hardcoded `_season_start()` in NCAAB Lambda

**File:** `lambda/ncaab_fade_revenge_daily/lambda_function.py` lines 66-74

The function has a hardcoded dict that maps season → season start date. It has no `2026-27` entry
and falls back to `2025-26` dates, which is wrong. Replace it with a lookup against
`season_dates.yaml`.

```python
# BEFORE (lines 66-74):
def _season_start(season: str) -> str:
    starts = {
        '2025-26': '2025-11-03',
        '2024-25': '2024-11-03',
        # ...
    }
    return starts.get(season, '2025-11-03')  # Wrong fallback

# AFTER:
def _season_start(season: str) -> str:
    from src.season_utils import get_season_dates
    return get_season_dates('ncaab', season)['season_start']
```
