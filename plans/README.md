# Plan File Naming Convention

`YYYYMMDD-NNN-slug.md`

| Part | Format | Example |
|---|---|---|
| Date | ISO date, no dashes | `20260907` |
| Sequence | 3-digit zero-padded | `001`, `002` |
| Slug | kebab-case, describes the work | `cursor-nav-polish` |

Sequence resets per project, not per day. Increment by 1 regardless of date gaps.
